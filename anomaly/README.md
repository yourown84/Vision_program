# 비전 검사 시스템

정상 이미지만으로 불량을 찾는 **어노멀리**, 불량 종류를 나누는 **분류**, 불량 영역을 픽셀 단위로 찾는 **세그멘테이션** 세 가지 방식과,
여러 라인 PC에 모델을 배포하고 결과를 모으는 **관리 서버**로 구성됩니다. 모든 기능은 브라우저 화면에서 버튼으로 조작합니다.

## 실행 파일 (더블클릭)

| 파일 | 역할 | 어디서 |
|---|---|---|
| `start_ui.bat` | 학습·검사 화면 (브라우저 자동 실행) | 학습하는 PC |
| `start_api.bat` | 검사 API 서버 (라인 프로그램이 호출) | 각 라인 PC |
| `start_agent.bat` | 관리 서버와 통신하는 에이전트 (모델 자동 설치) | 각 라인 PC |
| `start_manager.bat` | 관리 서버 + 대시보드 (http://서버IP:9000) | 서버 PC |
| `config.bat` | 관리 서버 주소, PC 이름, 포트 설정 | 모든 PC에서 수정 |

검은 창은 닫지 마세요. 닫으면 해당 프로그램이 종료됩니다.

## 데이터 준비 방법

- **어노멀리**: 정상 이미지만 폴더에 모읍니다 (50장 이상 권장). 불량 이미지가 있으면 별도 폴더에 두면 임계값이 더 정확해집니다.
- **분류**: 폴더 이름이 정답입니다. `데이터/good`, `데이터/scratch`, `데이터/dent` 처럼 클래스별 폴더에 이미지를 넣습니다 (클래스당 50장 이상 권장).
- **세그멘테이션**: `데이터/images/*.png` 와 같은 이름의 `데이터/masks/*.png` (흰색=불량, 검정=정상). 화면의 "세그 데이터 만들기" 탭으로 어노멀리 모델에서 마스크 초안을 자동 생성한 뒤 틀린 부분만 그림판으로 고치면 됩니다.

조명과 카메라 조건은 실제 라인과 같아야 합니다.

## 검사 설정 (상용 도구의 파라미터에 해당)

| 기능 | 위치 | 설명 |
|---|---|---|
| ROI (검사 영역) | 10번 탭에서 붓으로 칠해 저장 → 각 학습 탭의 "ROI 마스크 파일" | 칠한 영역만 학습·검사. 지그, 배경, 라벨을 빼면 오검 감소 |
| 증강 | 각 학습 탭 > 고급 설정 | 뒤집기, 회전, 밝기, 대비, 크기 변동. 라인에서 실제로 생기는 변동만 켜기 |
| 이중 임계값 | 2번 탭 (재검 임계값 / NG 임계값) | 재검~NG 사이 점수는 "재검"으로 분류해 사람이 확인. API 결과 `result` 가 OK / REVIEW / NG |
| 감도 | 2번 탭 (픽셀 임계값), 8번 탭 (픽셀 임계값, 최소 면적) | 이미지 판정과 별개로 불량 영역 표시의 예민함 조절 |
| 학습 세부값 | 각 학습 탭 > 고급 설정 | 배치 크기, 에폭, 학습률, 조기 종료, 클래스 불균형 보정 |
| 모델 종류 | 1번 탭 (PatchCore / PatchCore 경량 / Dinomaly), 4·7번 탭 (백본/인코더) | Dinomaly 는 DINOv2 파운데이션 모델 기반, 정확도 우선 |
| 모델 비교 | 11번 탭 | 같은 데이터로 여러 설정을 학습해 성능·속도 표로 비교 |

## 여러 PC 구성 순서

1. 서버 PC: `start_manager.bat` 실행. 대시보드 주소는 `http://서버IP:9000`.
2. 각 라인 PC: `config.bat` 의 `MANAGER_URL` 을 서버 주소로 바꾸고, `start_api.bat` 과 `start_agent.bat` 실행.
3. 학습 PC의 화면 "9. 배포" 탭에서 모델을 업로드하고, 라인 PC를 골라 배포 지정. 에이전트가 몇 초 안에 내려받아 교체합니다.
4. 라인 PC의 검사 결과는 관리 서버에 자동으로 모입니다 (대시보드 또는 배포 탭에서 조회).

## 라인 프로그램에서 호출 (API)

API 서버 주소가 `http://라인PC:8000` 일 때, 이미지 파일을 올리면 JSON 결과를 돌려줍니다. 설명서: `http://라인PC:8000/docs`

| 주소 | 기능 | 응답 예 |
|---|---|---|
| `POST /inspect` | 어노멀리 검사 | `{"result":"NG","score":78.9,"review_threshold":40,"threshold":50,"boxes":[[188,159,39,43]],"elapsed_ms":15}` (result: OK / REVIEW / NG) |
| `POST /classify` | 분류 | `{"label":"scratch","confidence":96.1,"probs":{...}}` |
| `POST /segment` | 세그멘테이션 | `{"result":"NG","defect_ratio":0.9,"boxes":[[171,90,27,29]]}` |
| `GET /status` | 올라온 모델 확인 | |

호출 예제: `client_example.py` (Python), `client_example.cs` (C#).

## 속도 (RTX 3070 Ti 기준, 이미지 1장)

| 방식 | 처리 시간 | API 왕복 |
|---|---|---|
| 어노멀리 (256px) | 약 15 ms | 약 21 ms |
| 분류 (224px) | 약 3 ms | 약 10 ms |
| 세그멘테이션 (256px) | 약 6 ms | 약 12 ms |

GPU가 없는 PC는 `config.bat` 에서 `INSPECT_DEVICE=cpu` 로 설정하면 CPU로 동작합니다 (느려짐).

## 파일 구조

- `core.py`, `core_cls.py`, `core_seg.py` : 학습·검사 로직 (화면과 분리) / `roi.py` : ROI 공통 / `experiments.py` : 모델 비교
- `app.py` : 브라우저 화면 / `server.py` : API 서버 / `manager.py` : 관리 서버 / `agent.py` : 라인 PC 에이전트 / `deploy.py` : 모델 묶기·설치
- `models/`, `models_cls/`, `models_seg/` : 학습된 모델
- `data/` : 학습 데이터 (샘플 생성기: `make_sample_*.py`)
